# Rock Paper Scissors Game

This is a simple command-line Rock Paper Scissors game built using Node.js. The game allows users to play against the computer in a best-of-three match format.

## Table of Contents

- [Features](#features)
- [Technologies Used](#technologies-used)
- [Installation](#installation)
- [Usage](#usage)
- [Contributing](#contributing)
- [License](#license)

## Features

- Command-line interface for user interaction.
- Best-of-three match against the computer.
- Randomized computer moves for fair play.
- Displays the result of each round and the final winner.

## Technologies Used

- **Node.js**: JavaScript runtime environment.
- **Chalk**: A library for styling terminal string output.
- **Inquirer**: A library for creating interactive command-line prompts.

## Installation

To use this Rock Paper Scissors game on your local machine:

1. **Clone the repository:**
    ```bash
    git clone https://github.com/Tayyabkhalid993/PIAIC56.git
    ```

2. **Navigate to the project directory:**
    ```bash
    cd PIAIC56/NodeProjects/Other_Projects/Rock_Paper_sessior
    ```

3. **Install the dependencies:**
    ```bash
    npm install
    ```

4. **Install the Rock Paper Scissors package:**
    ```bash
    npm i rock_paper_scissor_tayyabk993
    ```
