# BMI Calculator

This is a simple command-line BMI (Body Mass Index) calculator built using Node.js. The calculator prompts users to input their weight and height and then calculates their BMI along with a category indicating their health status.

## Features

- Command-line interface for user interaction.
- Calculates BMI based on user input (weight and height).
- Categorizes BMI into different health status categories:
  - Underweight
  - Normal weight
  - Overweight
  - Obese
- Provides clear and concise output.

## Technologies Used

- **Node.js**: JavaScript runtime environment.
- **Chalk**: A library for styling terminal string output.
- **Inquirer**: A library for creating interactive command-line prompts.

## Installation

To use this BMI calculator on your local machine:

1. **Clone the repository:**
    ```bash
    git clone https://github.com/Tayyabkhalid993/PIAIC56.git
    ```

2. **Navigate to the project directory:**
    ```bash
    cd PIAIC56/NodeProjects/BMI
    ```

3. **Install the dependencies:**
    ```bash
    npm install
    ```

4. **Install the BMI calculator package:**
    ```bash
    npm i bmi_tayyabk993
    ```
